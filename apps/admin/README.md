# SoraCargo - Global Admin Portal (Strictly Private)

Aplikasi kendali sentral superadmin (keuangan, master data tarif global, audit log, manajemen akun perusahaan shipper, dan konfigurasi sistem).

- **Akses Jaringan**: Strictly Private (Hanya IP VPN Admin / Laptop Developer via WireGuard/Tailscale)
- **Port Container**: 8003 (Tidak diekspos ke port publik)
- **Domain**: `admin.soracargo.internal`
