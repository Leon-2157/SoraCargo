# SoraCargo - Operator Portal (Regional VPN / Semi-Private)

Aplikasi portal armada dan dispatcher kargo untuk operator lapangan (update koordinat radar GPS, status bongkar muat kapal/pesawat/truk, manifest manifest jalan).

- **Akses Jaringan**: Semi-Private (Hanya IP VPN Gateway Regional / Kantor Cabang terkait)
- **Port Container**: 8002
- **Domain**: `ops.soracargo.com` (atau `ops-id.soracargo.com`)
