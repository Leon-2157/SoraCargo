# AI Logistics Assistant Service

Service mikro internal untuk asisten logistik AI (SoraBot) dan analisis manifest kargo otomatis:
- **Provider**: Google Gemini API / OpenAI API.
- **Interaksi**:
  - Chat streaming (Server-Sent Events) untuk portal customer.
  - Ringkasan manifest dan estimasi cuaca rute logistik maritim/udara otomatis di background worker.
